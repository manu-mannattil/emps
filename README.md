# Elastic microphase separation

[![arXiv](https://img.shields.io/badge/arXiv-2607.27516-d62728)](https://arxiv.org/abs/2607.27516)
[![arXiv](https://img.shields.io/badge/arXiv-2607.27516-d62728)](https://arxiv.org/abs/2607.27516)

The Python scripts in this repository require the standard Python
scientific stack ([NumPy][numpy] + [SciPy][scipy]).  Plotting requires
[Matplotlib][mpl] and [charu][charu].

## Description

Elasticity plays a key role in regulating phase separation in swollen
elastomers, where it can arrest macroscopic demixing between the polymer
network and solvent and stabilize domains of finite size. We show that
this microphase separation arises from a mismatch between the
characteristic length scales of elastic and thermodynamic interactions
and can be explained using conventional elasticity through a nonlocal
thermodynamic-elastic coupling imposed by volume conservation. The
theory reproduces the observed dependence of phase transition
temperature and domain size on elastomer stiffness under isotropic
swelling and further predicts how anisotropy modifies microphase
behavior. In particular, uniaxial swelling can stabilize lamellar
microphases and alter phase behavior, while spatial gradients in
stiffness produce corresponding variations in the characteristic
microphase size. These results provide a unified framework for
understanding and controlling elasticity-mediated microphase separation
in swollen polymer networks.
